Clicker Game on Godot 4

A simple clicker game for learning GDScript.

Features
- Clicking on the button increases the score
- Clicking power improvement with increasing price
- Auto-clicker (purchased and works automatically)
- Visual feedback (button animations)
- UI is blocked when there are not enough points

Controls
- Click on the button
- Buy improvements
- Enjoy the progress

How to run
1. Download Godot 4.x
2. Import the project
3. Run the Clicker.tscn scene
